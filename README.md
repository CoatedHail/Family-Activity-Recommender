# Family Activity Recommender — Simulation Code

Code accompanying "A Personalized Family-Activity Recommendation
System for Reducing Planning Burden in Parents with High
Perfectionistic Concerns and Intolerance of Uncertainty."

All data in this repository is synthetic. The generating rules are
specified explicitly in `generate.py` and documented in Section 3.3
of the paper.

## Files
- `generate.py` — activity catalog and synthetic data generator
- `experiments.py` — model comparison, feature ablation, noise sweep, ranking evaluation
- `sweep.py` — interaction-strength sweep (Table 5)
